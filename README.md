#  DIY Robotic Hand Project

This project was a challenging but rewarding build.  
It took a lot of trial and error to get the design working — and I learned a lot from the mistakes I made along the way.

---

##  Project Overview
The goal of this project was to build a **robotic hand** controlled by a **glove with DIY flex sensors**.  
When the glove bends, the hand’s cardboard fingers follow the same movement using strings and sensors.

---

##  Challenges & Setbacks
Like any hands-on project, there were several issues I ran into during the build:

### 1. Glove Size
The glove I used was **too small and tight**, which caused the **DIY flex sensors** to **snap or break** easily under tension.

### 2. Finger Mechanism
I used **strings** to pull the cardboard fingers upward.  
This created a problem where the fingers would **stay partially bent** instead of returning to a straight position.

### 3. Lack of a Return System
Since there was no proper mechanism to **push the fingers back down**, they didn’t unbend properly after flexing.

---

##  Lessons Learned
-  Use a **properly fitting glove** to reduce sensor stress.  
-  Reinforce or replace fragile DIY flex sensors with more durable materials.  
-  Replace strings with **thin metal wires or springs** to provide **a natural return force** when unbending the fingers.  
-  Design with **durability in mind** — small improvements in structure make a big difference in performance.
